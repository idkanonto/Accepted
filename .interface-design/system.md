# Accepted application folio

Light mode: warm canvas #f7f7f4, white paper, graphite #232735, indigo #5146cf.
Subtle layered shadow is the elevation strategy; borders stay quiet. 4px spacing
base. Controls are at least 44px high, with 10px corners; surfaces 14px and native
modals 20px. Desktop workspace rail is 224px; content is at most 1200px with
24–40px gutters. Mobile uses 20px gutters and a compact bottom destination bar.

Inter interface typography: 12px metadata, 14px body, 16/20/24px section headings,
28–36px page headings. Large type has tighter tracking; body copy 1.6 line height.
Fraunces provides the editorial home headline. JetBrains Mono and tabular numbers
serve timers, program codes and scores. Fonts stay local.

Folio signature: Plan / Prepare / Reflect navigation, numbered program slips,
quiet eyebrow labels, a prep → response → review sequence and annotation-like
Nova feedback. One focal task per page. No decorative statistics or fake outcomes.
Shared controls: Button, PageHeader, Panel, Badge, Notice, EmptyState, LoadingState,
Tabs, Dialog and InfoTip. Native select/input and dialog semantics are retained.

Motion: 160ms controls, 220ms surface entrance, transform/opacity only. Press
feedback is subtle. Respect prefers-reduced-motion; never hide content until a
scroll script runs. Public claims, data and API/persistence behavior stay intact.
